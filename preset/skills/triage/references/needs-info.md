# Needs-info triage notes

Post this when an issue moves to `needs-info`:

```markdown
> *This was generated by AI during triage.*

## Triage Notes

**What we've established so far:**

- point 1
- point 2

**What we still need from you (@reporter):**

- question 1
- question 2
```

Put everything settled during grilling under "established so far", so the work isn't lost. Each question is specific and actionable, never "please provide more info". Replace `@reporter` with the reporter's handle.
